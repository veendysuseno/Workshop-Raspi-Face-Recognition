# Raspberry Pi Face Recognition Omniwheels Robot

Workshop **Raspberry Pi – Face Recognition Omniwheels Robot** yang mempelajari dasar robot Omniwheels, navigasi berbasis web, serta implementasi **Face Recognition** menggunakan Raspberry Pi 3 dan Python.

## 🎯 Objectives

- Memahami konsep dan mekanisme **Omniwheels Robot**.
- Memahami navigasi robot berbasis **Web**.
- Memahami proses **Face Dataset Acquisition & Training**.
- Memahami algoritma **Face Recognition menggunakan LBPH**.
- Mengimplementasikan **Web-Based Face Recognition Robot**.

## 🛠️ Hardware

- Raspberry Pi 3
- Omniwheels Robot
- Motor Driver IBT2
- Webcam
- LiPo Battery
- PC / Laptop

## 💻 Software & Tools

- Python 3
- OpenCV
- PIL
- PuTTY
- HTML, CSS, JavaScript
- Bootstrap
- jQuery
- Advanced IP Scanner / Zenmap
- Net Analyzer

## 📚 Workshop Modules

### 1. Omniwheels Robot
- Pengenalan Robot Omniwheels
- Sistem roda dan pergerakan robot
- Motor Driver IBT2
- LiPo Battery

### 2. Web-Based Robot Navigation
- HTML, CSS, dan JavaScript
- Bootstrap & jQuery
- Web GUI untuk kontrol robot
- Navigasi Robot Omniwheels

### 3. Face Dataset & Training
- OpenCV dan PIL
- Face Detection & Feature Detection
- Akuisisi dataset melalui webcam
- Training dataset wajah

### 4. Face Recognition
- Algoritma **Local Binary Pattern Histogram (LBPH)**
- Implementasi Face Recognition dengan Python
- Threading pada Raspberry Pi
- Camera Threading
